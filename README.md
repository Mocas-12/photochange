# PhotoChange

一个简洁的前端图片处理工具：上传、裁剪、调整尺寸、加水印、格式转换（PNG/JPG/WebP/PDF）。全部在浏览器本地完成，无需安装、无需上传到服务器。

**在线使用**：<https://mocas-12.github.io/photochange/>

## 功能一览

- 上传方式：点击"选择图片"或直接拖拽图片到页面（支持 PNG / JPG / JPEG / WebP / BMP）。
- 画布：支持缩放、旋转、标尺网格辅助查看。
- 裁剪：自由 / 1:1 / 4:3 / 16:9 / 3:2，选区外部半透明遮罩便于观察。
- 尺寸：填写宽高并支持"锁定比例"，内置常用预设（头像、一寸/二寸证件照、公众号封面、小红书、HD/FHD 等）。
- 水印：可添加文字水印，九宫格位置 + 透明度可调。
- 撤销 / 重置：支持 Ctrl+Z 撤销，一键重置为原图。
- 导出格式：PNG / JPG / WebP / PDF。
  - JPG、WebP 支持质量调节（0.1–1），数值越小文件越小。
  - 支持"压到 N KB"目标体积压缩，自动搜索最接近的质量参数。
  - PDF 基于 A4 页面，图片自适应并居中。
- 文件名：导出前可自定义文件名。
- 状态徽章：画布右下角实时显示当前格式、分辨率、预估文件大小。
- 免费额度：内置 5 次免费导出额度，用尽后可激活专业版解锁无限导出。

## 使用步骤

1. 打开网页，下滑（或点击向下箭头）进入工作台。
2. 点击"选择图片"或直接拖拽图片到页面。
3. 通过编辑工具条选择"裁剪 / 尺寸 / 水印"进行编辑，支持撤销与重置。
4. 在底部导出条选择格式；JPG / WebP 可调质量，也可填写"压到 N KB"控制文件大小。
5. 输入文件名，点击"导出下载"。

## 常见问题

- 为什么 PNG 没有"质量"选项？
  - PNG 为无损压缩，通常不提供有损"质量"参数；文件大小主要由图片内容决定。
- 填了"压到 N KB"但导出 PNG 没生效？
  - PNG 无法按体积压缩，应用会提示并自动改用 JPG 压缩。
- PDF 的清晰度如何？
  - 实际是把当前画布转为 JPG 嵌入到 PDF 中；清晰度取决于画布尺寸与导出质量。
- 下载文件过大怎么办？
  - 先降低 JPG 质量，或填写目标体积（KB），或先缩小分辨率再导出。
- 隐私与安全？
  - 全部在浏览器本地处理，不会上传到服务器。

## 本地预览

无需安装依赖，直接用任意静态服务器或浏览器打开 `index.html` 即可。推荐方式：

```bash
python -m http.server 5173
# 浏览器访问 http://localhost:5173/
```
